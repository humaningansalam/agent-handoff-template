# Contributing to Agent Handoff Template

This repository contains starting Markdown documents and optional issue and pull request forms. The [repoctl](https://github.com/humaningansalam/repoctl) repository owns CLI behavior.

Read a changed document as a project author would: check that its wording is clear, its relative links resolve and any examples work in the intended project. This repository has no test suite.

Open one PR for one logical change. Explain the problem, the resulting guidance and the review you actually performed. Issues and pull requests may use English or Korean. Squash-merge the reviewed PR with a descriptive title, then delete its branch.
