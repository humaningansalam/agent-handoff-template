# Agent Handoff Template

Markdown starting documents for a project and work that continues across sessions.

Write the project requirements in `docs/PRD.md`. Copy `docs/tasks/TEMPLATE.md` when a piece of work needs a durable record, fill in its identity and goal, and keep the Handoff current as the work changes. The document can include findings, decisions, source links and results relevant to that work.

The optional `parent` field links related Tasks. `docs/BOARD.md` can provide an overview, and `docs/REPOS.md` can describe a project with multiple repositories.

The files can be edited directly. The separate [repoctl](https://github.com/humaningansalam/repoctl) CLI provides Task listing and status changes.
