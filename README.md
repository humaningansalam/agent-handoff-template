# Agent Handoff Template — document-only artifact

This is a self-contained, Markdown-first Task, Board, Handoff and document scaffold. It deliberately contains **no repoctl runtime, providers, scripts or installer**.

Start by reading `AGENTS.md`, editing `docs/PRD.md`, and creating a Task from `docs/tasks/TEMPLATE.md`. Add its file path to `docs/BOARD.md`. Record four precise Handoff fields before a handover. All project-specific decisions and verification remain human-authored.

`docs/template-contract.json` declares the document contract version. Optional external tools must validate compatibility without rewriting authored meaning.
