# Code Quality

For changes spanning agents, languages, or shared interfaces, follow the existing [AGENTS.md work loop](../../AGENTS.md#product-work-loop) and Task's Chosen scope. Read the relevant documentation and implementation; reuse established abstractions, domain terms, contracts, and settings. Express shared meaning and contracts idiomatically in each language while preserving module boundaries, type semantics, units, error meaning, and external compatibility. Change shared schemas at their source and regenerate affected outputs with the project's existing generator.

Use the repository's existing applicable formatter, lint, type, build, and test commands, versions, and configuration. Keep applicable settings consistent locally and in CI, and keep formatting cleanup separate where it would obscure behavior changes. Inspect the combined change, affected consumers, relevant generated or untracked outputs, and changes to check configuration for duplication, workarounds, and unnecessary abstractions. Do not mask failures as successful defaults or empty results. Check behavior and interface boundaries using [well-written tests](well-written-tests.md). Read actual local and CI check outcomes for the relevant revision: skipped or unrun checks supply no passing evidence. Reuse available results when their relevant inputs are unchanged.
