# v0.13.0

This release makes Task and Handoff current-state records, keeps valid Knowledge visible through projection failure, separates Graph relation availability from optional derived components, and aligns document collection with `docs/PRD.md`, `docs/architecture/`, `docs/specs/`, `docs/adr/`, and `docs/research/`.

It adds warning-only Task audit, dry-run-first generated-slop migration for live Tasks, direct Knowledge fallback and unique digest relocation, explicit Knowledge status semantics, and graceful Graph degradation. It does not update adopter workspaces, rewrite immutable archived Tasks, implement MCP, or own external agent/model/deployment execution.

See `docs/workflows/v0.13-rollout.md` for exact upgrade and migration commands and limitations.

## Work-path query and measured benchmark

New read-only commands `graph workflow` and `graph workflow-benchmark` return entrypoint/implementation/dependent/test stages, provenance, source freshness, path recall, and **separate confirmed-path recall**. Unresolved HTTP method calls and Rust/Dart lexical fallback paths remain labeled candidates, not precise relations. The four preserved adopter snapshots were inspected without mutation: Basic ML API, Kinport, Gakza, and Cops-and-Robbers achieved full expected *path discovery* in this local read-only comparison, while stale Graph inputs limited confirmed-path recall (25%, 0%, 0%, 0% respectively). This does **not** establish all-adopter precision or completed test execution. See `docs/research/graph-language-indexes.md` for unsupported languages and future index adapters.
