# v0.14.0 — current work, source-linked evidence, one-time conversion

`v0.13.0` was a published intermediate release, not accepted completion of the unified product contract. This version removes the independent Context CLI and Context Pack/export system, uses the current Task/Board/Workflows operating model and Graph/Knowledge navigation, removes the ordinary `--compact` resume split and duplicate historical Handoff output, and supplies explicit one-time historical Task and v1 Knowledge conversions.

Graph keeps a valid materialized snapshot usable when optional provider/evidence components degrade. The optional Tree-sitter provider adds source-ranged syntax definitions, conservative unqualified local calls and Rust module linkage for Rust, Go, Java/Kotlin and Swift. Dynamic/type-dispatched and unresolved cross-file relationships remain partial rather than fabricated. Graph workflow benchmarking scores required stages, first-path correctness, source provenance and false positives instead of just candidate recall.

The fixed `docs/PRD.md` entry and optional current architecture/specs/adr/research paths are exemplified in `examples/project/`. No adopter-owned product code, Tasks, archives or indexes were mutated by the source release work. Migration is opt-in and documented in `docs/workflows/v0.14-rollout.md`; this release does **not** perform the adopter rollout.

The evidence SQLite index schema is v9 and retains source-declared document adoption roles; drafts and proposals remain reference material after materialization and retrieval. Older derived indexes require an explicit Graph rebuild. No user-owned project documentation or repository was rewritten during source release preparation.

## Evidence from representative source, not product release proof

- **Kinport (read-only source):** the structural Tree-sitter adapter parsed three real Rust files with 318 source-ranged symbols, 262 same-file conservative direct calls, no failed paths, and one exact `main.rs` to `audio_clock.rs` Rust module relation. A native Node/Point crash found on complex real Rust files was fixed with a bounded iterative walk and byte-offset source anchors; the regression suite includes a large Rust module.
- **Basic ML API (read-only stale snapshot):** `/predict`, `ModelManager.predict`, and API/concurrency test paths are recovered as current-source candidates, not compiler-confirmed dynamic runtime dispatch. A false-positive helper path was removed from the primary implementation stage.
- **Gakza (read-only stale snapshot):** Dart source/test/dependent candidates retain explicit incomplete status; a stale snapshot is not evidence that a precise current relationship was checked.
- **Cops-and-Robbers (isolated source copy):** five real Dart source files were copied to a throwaway workspace. A missing/stale Graph produced partial source evidence; after isolated Graph rebuild the real `main` symbol was provider-confirmed and 512 typed CALLS edges were present in the isolated source subset. No adopter repository or its derived state was rebuilt. This does not assert that all callers/tests in the complete product are covered.

Workflow benchmark `path_recall` is only candidate-inclusive navigation. `required_stages_precise`, provenance, negative/false-positive cases, and `task_navigation_complete` remain distinct: in the stale adopter snapshots, the four real-workflow cases are **not** all precise/completed. The optional AST adapter is not a substitute for a compiler/type checker; ambiguous member dispatch and dynamic links remain partial.
